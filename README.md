# Проект Todo_go создан для проверки знаний, полученных при прохождении курса Go-разработчик с нуля на платформе Яндекс практикум
Проект Todo_go представляет собой веб-сервер, который реализует функциональность простейшего планировщика задач

Планировщик хранит задачи, каждая из которых содержит дату дедлайна и заголовок с комментарием. Задачи хранятся в базе данных  "scheduler.db" в корневом каталоге приложения

Каждая задача может повторяться в зависимости от заданных правил повторения

С каждой задачей можно выполнять определенные действия:
    - отметить как выполненную
    - откорректировать
    - удалить

Задания повышенной трудности не выполнялись

Для локального запуска кода необходимо в корневом каталоге ввести команду "go run cmd/main.go" либо сделать билд "go build cmd/main.go" и  запустить приложение с исполняемого файла, скомпилированного в корневом каталоге.
После запуска приложения в браузере необхолимо ввести адрес "localhost:7540", где будет отображен интрефейс пользователя

Запуск тестов производится в командной стороке командами из списка "run_tests.txt", находящегося в поддирректории "/tests"
